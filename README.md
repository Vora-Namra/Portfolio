# Namra Vora — Portfolio

Personal portfolio built with React, Vite and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Deploy the repository root on Vercel or Netlify. Build command: `npm run build`. Output directory: `dist`.

See the source files for the portfolio sections, responsive styling and interactions.
